What is Node.js?

Node.js is a runtime that lets you run JavaScript on the server — outside the browser. Before Node, JavaScript only ran inside web pages. Node took Google Chrome's fast V8 engine and let it power backend servers, tools, and APIs.

It is famous for being event-driven and non-blocking: instead of waiting for one task to finish before starting the next, it juggles many requests at once. That makes it excellent for APIs and real-time apps that handle lots of connections.

What is Express? the framework

Express is the most popular web framework for Node.js. Node gives you the engine; Express gives you a clean, simple way to define routes (like GET /orders) and handle requests and responses. This app uses Express to expose the orders API you can try below.

API Endpoints

  • GET/health — service health check
  • GET/orders — list all orders
  • POST/orders — create a new order
